# Screenshot & Clip Organizer
## Features:
Organize new screenshots and clips based on game name.
* Add **multiple unsorted source paths** (Also searches through subdirectories)
* **Renames** media to name of game, in combination with file creation time
* **Quick-Add** supported plattform's source path (currently only Steam)
* **Update folder if game name was changed** in Playnite Library ( *e.g. changing 'Grand Theft Auto: V' to 'Grand Theft Auto: V (Legacy)' automatically renames the associated folder accordingly on next sort*)
* **Move or Copy** Files Option (*Default: Move*)
* **Detects files of non-media type** with option to include or exclude from sorting process (List of file types can be customized)
  
*Note: This extension does **not** organize any Screenshots taken before extension installation.*

## Set-Up:
1. Navigate to extension settings
2. Select a target path to sort media into.
3. Add any unsorted source directories, you wish to be organized.
4. (Check file copy option if you want files to be duplicated)
5. Save settings
